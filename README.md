# Cart Assignment

## Overview
This project is a responsive shopping cart page built using plain HTML, CSS, and JavaScript. The cart data is fetched from an API and dynamically rendered on the page.

## Features
- Fetch cart data from an API
- Display cart items dynamically
- Responsive design for different screen sizes
- Basic quantity and total price calculations
- Simple UI without external libraries

## Technologies Used
- HTML
- CSS
- JavaScript (ES6+)
- Fetch API

## Setup Instructions
1. Clone the repository:
   ```sh
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```sh
   cd assignment
   ```
3. Open `index.html` in a browser.

## API Endpoint
Ensure the API providing cart data is accessible. The fetch request should be updated accordingly inside the JavaScript file.

## Folder Structure
```
shopping-cart-assignment/
│── index.html  # Main HTML file
│── style.css  # CSS for styling
│── script.js   # JavaScript for handling cart logic
```

## Usage
1. Open the `index.html` file in a browser.
2. The cart items will be loaded dynamically from the API.
3. Users can view items and see price calculations.

## Responsive Design
- Mobile-friendly layout using CSS media queries.
- Adjusts elements based on screen width.
